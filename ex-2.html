HTML Forms & Media Elements

Quick Facts
TopicHTML Forms
LevelBeginner
Duration2 Hours
PrerequisitesEx-1: HTML Basics
StandardsHTML5 / W3C

HTML Forms are the primary mechanism for collecting user input on the web. All forms begin with the <form> tag and end with </form>. The form tag has two main attributes: METHOD (how data is sent) and ACTION (where data is sent).

<form action="/action_page.php" method="get"> ...form elements... </form>

A <form> element can contain: <input>, <textarea>, <button>, <select>, <option>, <fieldset>, and <label>.

3. Textarea

The <textarea> tag defines a multi-line text input control. The size can be set by rows and cols attributes.

<textarea rows="4" cols="50"></textarea>

4. Select & Option

The <select> element creates a drop-down list. <option> tags define available choices.

<select> <option value="volvo">Volvo</option> <option value="saab">Saab</option> </select>

5. Fieldset & Legend

The <fieldset> tag groups related elements and draws a box. <legend> provides a caption.

<fieldset> <legend>Personalia:</legend> Name: <input type="text"> Email: <input type="text"> </fieldset>

6. Media Elements

6.1 Audio

The <audio> element is used for embedding sound content.

<audio controls> <source src="1.mp3" type="audio/mpeg"> </audio>

6.2 Video

The <video> element embeds video content.

<video controls> <source src="1.mp4" type="video/mp4"> </video>

6.3 Embed

The <embed> tag defines a container for external applications or plug-ins.
